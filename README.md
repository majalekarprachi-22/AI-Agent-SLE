## Student Assistant AI Agent

### Objective
This project is developed as part of the AI-Augmented Workflow SLE activity. The objective is to build a simple student assistant agent and learn responsible use of AI-assisted coding.

### Tools Used
- Python
- GitHub
- GitHub Copilot
- Visual Studio Code

### Features
- Greets the user
- Accepts the user's name
- Responds to basic queries
- Provides simple study guidance
- Gives basic Python information
- Handles unknown queries

### How to Run
Run the following command:

python agent.py

### AI Assistance
AI assistance was used during the development process. AI-generated suggestions are reviewed, tested, and modified by the student where required.

### Testing
The agent was tested with inputs such as:
- hello
- study
- python
- bye

### Project Files
- `agent.py` - Basic Student Assistant Agent
- `Contribution_Log.md` - AI Contribution Log
- `README.md` - Project documentation

### Learning Outcome
This activity helped me understand AI-assisted coding, GitHub workflow, code verification, error correction, and transparent documentation of AI contributions.
